# Git Practice

## Interesting Article

[**A new worst coder has entered the chat: vibe coding without code knowledge**](https://stackoverflow.blog/2026/01/02/a-new-worst-coder-has-entered-the-chat-vibe-coding-without-code-knowledge/)

I found this article interesting because it discusses how AI coding tools can make it possible for people with little programming experience to create applications. The author describes using an AI tool to build an app and shows how quickly it could produce something that appeared to work.

What interested me most was that the app still had problems with security, organization, and testing. It shows why understanding the code is still important even when AI can generate much of it. I think AI coding tools are useful for learning and experimenting, but developers still need enough knowledge to understand and evaluate what the AI produces.
